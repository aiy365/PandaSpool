## 0. 你拍板后的产品形状

```text
PrintPilot = 耗材知识库
           + 人工架子账
           + A1 只读机台（拓竹云 MQTT，跑在 yby）
           + 封箱/车间空气档案
           + 萤石预览 + 易微联执行器
```

| 空间 | 是什么 | 评判标准 |
|---|---|---|
| **仓内 enclosure** | A1 **已经封箱**，隔板另一侧就是车间 | **材料污染性**：这种料正在打时，箱里脏不脏、净化器有没有把脏东西吃掉 |
| **仓外 room** | 一个房间 | **国家室内 / 环境空气口径**：人待着安不安全 |

隔板很近：**一套主从硬件**，线穿隔板。门磁、开关门逻辑 —— **整项删除**。

易微联只做通断：

| 插座 | 策略 |
|---|---|
| 仓内净化器 A | **长开**（封箱循环过滤） |
| 仓内净化器 C | **A1 工作中 + 结束后 30 分钟**（打印加强） |
| 车间净化器 B | **有人时开** |

补光灯：监控页手动开关，不绑门。

## 1. 污染科学：仓内到底该测什么

FDM 排放是两路，不是一路。

| 路 | 是什么 | ABS | 劣质 / 高填充 PETG | 合格 PETG / PLA |
|---|---|---|---|---|
| **超细颗粒 UFP** | 约 10–100 nm，能进肺泡 | 最高，常比 PLA 高 1–2 个数量级 | 明显高于合格 PETG | 低到中 |
| **可测颗粒 PM1/2.5/10** | 光学粒径，家用传感器能读 | 打印中 UFP 为主；**打完后团聚**，PM2.5 往往后抬 | 颗粒偏多、添加剂不稳 | 较低 |
| **VOC** | 苯乙烯等有机气体 | **苯乙烯为主**，刺鼻 | 增塑剂 / 残留单体 / 杂味，TVOC 乱跳 | 低 |

文献共识（Romanowski 2023、Bernatikova 2021、车间实测）：

- ABS / ASA：苯乙烯 + 大量 UFP。封箱是为了把脏空气关在箱里，再靠 **HEPA + 活性炭** 循环。
- PETG：气味常不明显，但 UFP 仍可到 ABS 的约 1/10，**远高于 PLA**。劣质 PETG 的颗粒和 VOC 都更接近「脏料」而不是「无味就没事」。
- 打印结束后 UFP 会团聚成更大颗粒，**PM2.5 可能打完才升高**。所以「打完 30 分钟还要跑净化器」有科学根据，不是拍脑袋。

### 1.1 PM1 / 2.5 / 10 要不要进仓内？要

家用 PMS5003 **测不到真正的 UFP**（颗粒太小）。但仍要测 PM1/2.5/10，理由：

1. 打完后团聚，PM 会变成「封箱里还脏不脏」的可见指标。
2. **仓内 vs 仓外同一时刻对比** = 封箱有没有漏、净化器有没有用。
3. 劣质 PETG 往往先在颗粒上露馅，不一定先有臭味。
4. 仓外必须用 PM2.5/PM10 对齐国标；仓内用同一套探头才横得过。

仓内另外 **必须有 VOC 指数**（SGP41 一类）。否则 ABS 的苯乙烯完全看不见。这不是实验室级苯乙烯 ppm，是「这料相对基线脏了多少」的 Rel 指标，后台要存曲线。

不做的：门磁、CO2（以后）、昂贵的冷凝核计数器（真 UFP）。

### 1.2 两套评判，不要用错

**仓内（材料污染）—— 不对齐国标达标，封箱打印 ABS 时国标必爆。**

用「这次打印的污染画像」：

| 指标 | 怎么用 |
|---|---|
| 打印前 10 分钟基线 | 温湿度、PM、VOC 的箱内背景 |
| 打印中峰值 / 中位数 | 相对基线的倍数 |
| 结束后 30 分钟衰减 | 半衰期；净化器 C 是否该继续 |
| 仓内 − 仓外 PM/VOC | 漏箱：仓外跟着仓内涨 |
| 料种画像 | 同品牌同系列多次打印的分布；某卷 PETG 的 VOC/PM 若像 ABS，标「排放异常」 |

后台每条打印任务挂一张空气卡片：料、开始结束、仓内曲线、仓外曲线、峰值、衰减。

**仓外（房间，国家标准）—— 给人待的。**

房间优先套 **《室内空气质量标准》GB/T 18883-2022**（住宅/办公，车间参照）：

| 指标 | 限值 | 平均时间 |
|---|---|---|
| PM2.5 | ≤ 50 µg/m³（0.05 mg/m³） | 24 h |
| PM10 | ≤ 100 µg/m³（0.10 mg/m³） | 24 h |
| TVOC | ≤ 0.60 mg/m³ | 8 h |
| 甲醛 | ≤ 0.08 mg/m³ | 1 h |

展示层同时算一套人熟悉的 **AQI 配色**（HJ 633：优 / 良 / 轻度…）。实时值用滑动 1 h / 24 h，卡片上写清「实时」和「24h 是否超标」，避免拿瞬时值冒充日均达标。

GB 3095 是室外环境空气，不作为房间主标准；AQI 色带只当 UI。

SGP41 给出的是指数，**不能写成「TVOC = 0.12 mg/m³ 已达标」**。页面必须写：`TVOC 指数（非国标法定方法）`。PM 才是和国标能对上的数。

### 1.3 针对性监测手段

| 风险 | 探头 | 放哪 |
|---|---|---|
| 颗粒（含打完团聚） | PMS5003 或 PMSA003，出 PM1/2.5/10 | **仓内 + 仓外都要**，否则不能判断漏箱 |
| ABS 苯乙烯 / 劣质料 VOC | SGP41（VOC 指数 + NOx 指数） | **仓内必上**；仓外可选（看漏） |
| 热管理 / 封箱是否过热 | SHT40 温湿度 | 仓内 + 仓外（对照） |
| 人在不在（开车间净化器） | LD2410C | **只在仓外** |
| 甲醛（劣质料、个别 PETG） | 第一期不做独立电化学；PMS5003S 的甲醛交叉干扰大，当参考都勉强 | 以后 |

## 2. 硬件：一块主板，线穿隔板

仓内外只隔一层板，**不要两套独立 WiFi 板**。

```text
[仓外 / 车间]                    隔板         [仓内 / 封箱]
  ESP32-S3 主控  ←──── UART 或 I2C 排线 ────►  子板（无 WiFi）
  · WiFi → 直连 3d.bstccc.cn
  · LD2410C 人体
  · PMS5003 仓外颗粒（国标）
  · SHT40 室温
  · 5V 供电、天线
                                     · SHT40 仓温仓湿
                                     · SGP41 VOC
                                     · PMS5003 仓内颗粒（材料）
```

**主端在仓外。** 人体必须在人活动的一侧；WiFi、供电、天线都在箱外更稳。箱内只挂被动传感器，热和塑料气少伤主板。

子板用现成 I2C 扩展或一块没焊天线的 C3，只做从机。排线：4 芯（GND、5V、SDA、SCL）或 4 芯 UART，孔用橡胶塞，尽量少漏气。

主控固件每 10–30 s（或超阈值）`HTTPS POST` 到 yby，**不经过 D2**。

第一期 BOM 大约 120–180 元（两颗 PMS + SGP41 + LD2410C + SHT×2 + ESP32-S3）。

## 3. 萤石 CS-C6H / CS-XP1

两款都是萤石云台消费机，走萤石云视频 App。

| | CS-C6H | CS-XP1 |
|---|---|---|
| 年代 | 2016 左右，720p 老云台 | 2019 左右，约 2MP |
| 第一期上 `3d.bstccc.cn` | **萤石开放平台 EZUIKit** | 同左 |
| 局域网 RTSP | C 系列多数可在「局域网设备预览 → 本地服务」打开；C6H 很老，**以你 App 里有没有「本地服务 / RTSP」为准** | 同左，成功概率高于 C6H |
| 第一期 | **不做 RTSP、不上 D2、不在公网站内嵌家里 554** | 同左 |

若 C6H 开放平台取流失败（老设备偶发），只保留 XP1 上云，C6H 当 App 备用。

## 5. 技术栈：整系统重开，不沿旧路

旧栈（Python 标准库 HTTP + 手写契约 + 1700 行页面 + 在旧 SQLite 上叠功能）**整段退役**。生产数据只做只读迁移，新系统新库新进程。

### 5.1 为什么换

| 旧问题 | 新系统要求 |
|---|---|
| 一个 HTTP 文件扛档案 + 以后还要扛 MQTT、空气、摄像机 | 长驻连接 + 定时策略 + 文件 + 网页必须是一个设计过的单体 |
| 前后端类型靠人抄 | 一份 schema 生成 API 和页面类型 |
| 3.6 GB、无 Docker | 一个运行时、两个 systemd 单元封顶 |
| 服务器已有 Node 22 | 用它，不再为旧 Python 包续命 |

### 5.2 选定栈

| 层 | 选定 | 不选 |
|---|---|---|
| 语言 | **TypeScript / Node 22** | 继续堆旧 Python 包 |
| HTTP | **Hono**（轻）或 Fastify | 手写 `BaseHTTPRequestHandler` |
| 校验 / 契约 | **Zod** → 导出 OpenAPI，前端生成类型 | 手工接口文件 |
| 数据库 | **SQLite + Drizzle**，新文件 `workshop.sqlite3` | 在旧 `material-lab.sqlite3` 上 ALTER 到死 |
| 长驻 | 同进程 worker：拓竹 MQTT、易微联轮询、净化器策略、空气聚合 | 单独 HA / Redis / 消息队列 |
| 前端 | **新 Vite + React + TanStack Query/Router**，按「档案 / 机台 / 空气」拆路由 | 旧 `InventoryDashboard.tsx` |
| 鉴权 | 会话 + Argon2id，Cookie | 抄旧 scrypt JSON 也行，但代码重写 |
| 静态 / TLS | 继续 **Caddy** 反代到 127.0.0.1 | 不换 Nginx、不上 Docker |
| 文件 | `/var/lib/printpilot/` 新目录，资料仍本地盘 | 对象存储 |
| 传感器 | ESP32-S3 固件 **独立小仓**，HTTPS + 设备令牌 | 经 D2 MQTT |
| 拓竹 | yby 上 MQTT.js，只订 `report` | 本地 8883 |
| 易微联 | 酷宅开放平台 v2 | 刷 Tasmota |
| 萤石 | 服务端 token + EZUIKit-JS | 第一期 RTSP |

进程：

```text
printpilot-web.service      Node：HTTP + 静态
printpilot-worker.service   Node：MQTT + 策略 + 聚合
```

内存目标：两进程合计常驻 < 400 MB，给 Caddy 和系统留余量。

### 5.3 领域模型（新库，不是旧表改名）

```text
Product / Color / Source / Claim / Preset / Measurement
InventoryLot          # 未开封 n + opened: boolean，无百分比
BambuAccount / PrinterSnapshot / PrintSession
Actuator              # ewelink 通道：light | purifier_box_always | purifier_box_print | purifier_room
AirSample             # zone, pm1, pm25, pm10, voc_index, t_c, rh, presence
AirEpisode            # 对齐一次 PrintSession 的仓内/仓外曲线摘要
Camera                # ezviz_cloud | 以后 generic_rtsp
```

库存：`unopened_spools` + `has_opened_spool`。Excel `1.5` 不再是一等公民；导入时问你「当成 1 未开封 + 1 开封」还是拒绝小数。

旧库 13 产品 / 52 颜色：**只读导出 → 新库导入**，生产旧服务第一期双轨，切流前你确认。

## 6. 后台必须有的空气呈现

这是功能，不是传感器附赠。

1. **实时机台页**：仓内 / 仓外两列。仓内：PM1/2.5/10、VOC 指数、温湿度、相对基线。仓外：PM2.5/10、AQI 色、24h 是否超 GB/T 18883、有人/无人、温湿度。
2. **时序**：默认 6 h / 24 h / 7 d；仓内仓外可叠在一张图上（漏箱一眼看到）。
3. **按打印归档**：每次 PrintSession 自动切一段 AirEpisode。列出料名、峰值 PM/VOC、相对基线倍数、结束后 30 min 是否降下来。
4. **料种排放画像**：同一产品颜色多次打印的箱线图。用来支撑「这卷 PETG 不像合格 PETG」。
5. **执行器状态**：三路净化器、补光，现态 + 最近一次策略原因（「打印中加强」「有人」「长开」）。

策略引擎（worker，可配置，默认真做）：

```text
purifier_box_always     = ON
purifier_box_print      = A1 stage 属于打印中
                          OR (打印结束起 30 分钟内)
purifier_room           = presence == true
light                   = 仅手动（监控页）
```

A1 状态只读来自 yby 上的云 MQTT，不经过 D2。
