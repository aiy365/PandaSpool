## 接线（仓外一块板）

```
ESP32-C3
  5V / GND     →  PMS5003 VCC / GND
  UART TX/RX   →  PMS5003 RX / TX     （注意交叉，3.3V 逻辑一般可直连）
  I2C SDA/SCL  →  SHT30
  UART2 或 GPIO →  LD2410C TX/RX
```

PMS5003 进风口朝房间，离墙 ≥2cm，别对着净化器出风口。  
LD2410C 朝人走动方向，别对着封箱里的喷头运动。

## 货到先通这三件事

1. 板子能联网，POST 出 `pm25 / pm10 / t_c / rh / presence`。  
2. 人走进房间，`presence` 变 true，网页能开车间净化器（或先看状态）。  
3. 页面能画 24h PM2.5 曲线，对照 50 µg/m³ 色带（写明参考）。
