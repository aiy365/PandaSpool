## 0. 先读这三句

1. **打印机保持云模式。** 不影响 Bambu Handy、不影响 Bambu Studio。
2. **不做第三方打印控制。** 不暂停、不继续、不停打、不调温、不改风扇、不改 AMS、不代发 3MF / 切片任务。这些继续交给 Handy / Studio。

## 1. 四个系统分别是什么

它们看起来都跟「打印 + 耗材」有关，回答的问题完全不同。不要合成一个大而全的 Mars 复刻。

| | PrintPilot 耗材实验室 | Mars Printer Hub | 拓竹官方（Handy + Studio + A1） | 易微联 / Sonoff 生态 |
|---|---|---|---|---|
| 核心问题 | 这款料是什么参数、资料从哪来、架子上还有几卷 | 槽位这卷还多重、这次打印扣了多少、订单赚不赚 | 切片、发任务、看打印、换色、校准 | 灯、插座、继电器、传感器怎么开关和联动 |
| 库存语义 | 人工盘点：未开封卷 + 开封余量%；**不按任务扣** | AMS 槽位绑定 + **按打印自动扣重** | AMS Lite 余量是挤出长度估算，不是称重 | 无耗材概念 |
| 和打印机的关系 | 原任务书刻意不接打印机 | 绑定拓竹账号，云 MQTT | 本体 | 完全外挂，接市电/灯/风扇 |
| 和 Handy/Studio | 无关，零冲突 | 走云账号，不要求 LAN Only | 官方自己 | 无关 |
| 你现在的状态 | `3d.bstccc.cn` 已上线；13 产品 / 52 颜色 / SQLite | 公网 `hcgl.top` 免费到 2027-04-17；私有部署收费 | 日常在用 | 已有多台设备，含三联继电器 |
| 资料深度 | 厂家 / 商家 / Studio 预设 / 实测分层，冲突并存 | 耗材档案较薄，重点是绑定与重量 | Studio 内置预设 | 无 |

**Codex 把 PrintPilot 做成耗材档案后台，产品方向没有写错。** 有问题的是实现方式（手写 HTTP、巨型文件），以及如果要叠「机台只读 + 易微联联动」，那是新产品边界，不是把现有看板再堆一层。

Mars 文档原话：私有部署 ≠ 打印机「局域网模式」；不影响 Handy / Studio。他们走的是 **绑定拓竹账号 → 云 MQTT Token**。Mars 私有部署截图里的主灯/副灯、舱内高清、电子秤扣重，大量是 **H2D + 外设**，不是 A1 原生。

## 2. 已拍板的边界

### 2.1 打印机模式（硬约束）

A1 从固件 `01.05.00.00`（2025-06）起带 Authorization Control + Developer Mode。

| 打印机模式 | Handy | Studio 云打印 | 第三方读状态 | 第三方打印控制 | 结论 |
|---|---|---|---|---|---|
| **云模式（保持联网）** | 正常 | 正常 | 可以 | 新固件基本不行 | **唯一允许的模式** |
| 只开「局域网实时画面」但不进 LAN Only | 正常 | 正常 | 可以 | 基本不行 | H2 系列才有独立 RTSP 开关；A1 通常没有 |
| LAN Only | **挂** | 仅局域网直连 | 可以 | 旧固件可以 | **禁止** |
| LAN Only + Developer Mode | **挂** | 仅局域网直连 | 可以 | 可以（官方不支持） | **禁止** |

官方口径：

- **需要授权、第三方做不了**（除非 Developer Mode）：绑定/解绑、远程视频、刷固件、发起打印、运动 / 温度 / 风扇 / AMS / 校准。
- **不需要授权、第三方还能做**：MQTT 状态推送（Home Assistant 这类只读）、SD 卡本机开打。
- Developer Mode **不能连 Bambu Cloud**，Handy 必挂。

你已明确：**第三方打印控制整类砍掉**。因此本文不再把 pause / resume / stop / 调温 / 发任务列为可选功能。

Access Code 在 A1 上往往要进一下 LAN Only 页才能看见。**看完立刻关掉**，不要保持 LAN Only。

### 2.2 明确不做（打印侧）

| ID | 不做 | 原因 |
|---|---|---|
| X01 | 暂停 / 继续 / 停止打印 | 你已否决；新固件也拦 |
| X02 | 远程调喷嘴 / 热床 / 风扇 | 同上 |
| X03 | 代发 3MF / G-code / 云打印 | 同上；且抢 Studio |
| X04 | 改 AMS 槽位设置、写回耗材类型 | 抢 Handy，且要授权 |
| X05 | 开 LAN Only / Developer Mode | 挂 Handy |
| X06 | 复刻 Mars 主灯 / 副灯 | A1 无舱灯 |
| X07 | 把 PrintPilot 做成多租户 SaaS / 社区市场 | 原任务书禁止 |
| X08 | 按库存自动推荐 3MF 材料 | 原任务书禁止，除非你改口 |
| X09 | 云服务器直连家里打印机 `:8883` | 暴露控制面，且 6 Mbps 不值 |
| X10 | Newifi D2 上跑 Home Assistant / 完整 Hub | MT7621A 扛不住 |
| X11 | 刷 Tasmota / ESPHome 作为默认方案 | 能做，但会削弱或丢掉易微联 App；除非你主动放弃官方 App |

### 2.3 明确可以做（和「不控制打印机」不冲突）

- 只读：打印状态、温度、层数、AMS Lite 托盘、HMS 错误。
- 自己的业务账：耗材档案、人工库存、可选机台绑定。
- **易微联设备的开关控制**：灯、烘干、排气、打印机市电。
- 用「打印只读状态」去**触发**易微联场景（打印中禁止拉闸、打印结束延时关排气）。

## 3. 硬件与部署现实

### 3.1 拓竹 A1（对比 Mars 截图里的 H2D）

A1 是开放机，不是封闭机。

| A1 实际有 | A1 没有 / 很弱 |
|---|---|
| 热床 / 喷嘴温度、层数、进度、剩余时间、阶段 | 腔体、仓温、舱门、主灯/副灯 |
| AMS Lite：最多 1 台、4 色；MQTT 有颜色 / 类型 / K 值 / 估算余量 | AMS 2 Pro 湿度、烘干、完整 RFID 资产管理 |
| 外挂料盘（External Spool） | 封闭舱那种高清舱内画面 |
| 喷嘴 / 热床向摄像头，画质差，多为 JPEG | H2 本地 RTSP「局域网实时画面」 |
| 提示音开关 | 腔体加热 |
| 本地 MQTT `:8883`（`bblp` + Access Code）只读 | 新固件下第三方打印控制 |

AMS Lite **不知道真实克数**，只知道挤出长度再换算。Mars「电子秤校准 / 自动扣重」是外挂秤 + 自己记账，不是拓竹原生。

### 3.2 Newifi D2（SOC MT7621A）

- MIPS 双核约 880 MHz，常见 **512 MB RAM**，闪存很小。
- 适合：OpenWrt、frp / nps / cloudflared、nginx、**很瘦的 Go/Rust 代理**、USB 接秤、定时抓一帧 JPEG、**局域网发现易微联设备**。
- 不适合：Home Assistant、Python+React 看板、视频转码、Docker 全家桶。
- 只配当 **局域网探针 / 端口映射前端 / 传感器与继电器网关**。

### 3.3 腾讯云 yby（`159.75.227.95`）

摘自 2026-08-15 台账：

| 项 | 值 | 含义 |
|---|---|---|
| 规格 | 4C / 3.6 GB / 70 GB / 6 Mbps / 600 GB 月流量 | 内存和上行都紧 |
| 系统 | Debian 12，无 Docker / Nginx / Redis | 继续单进程 + Caddy |
| 已占用 | PrintPilot `127.0.0.1:8765` + Caddy 80/443 | 入口已是 `3d.bstccc.cn` |
| 空闲 | 约 2.6 GB | 再塞 HA 或实时转码会挤爆 |
| 教训 | OpenClaw 曾独占约 1 GB，已卸载 | 云上不要再上重型常驻 |

云服务器适合：耗材档案、订单、通知出站、AI 接口、备份、**易微联云 API 出站控制**。  
不适合：实时画面中转、家里 MQTT 的唯一节点、HA。

### 3.4 推荐拓扑

```text
[拓竹 A1 保持云模式]
        │  Handy / Studio 继续走官方云（发任务、暂停、调温全在这里）
        │  我们只读：云 MQTT 和/或 家里 MQTT:8883
        ▼
[易微联设备]  三联继电器 / 插座 / 可选功率计
        │  官方 App 继续可用
        │  我们：云 API 或局域网协议去开关通道
        ▼
[Newifi D2]
        │  瘦代理：打印机状态转发、易微联局域网、可选 USB 秤、端口映射
        ▼
[腾讯云 Caddy]
        ├── PrintPilot 档案 / 库存（已有）
        ├── 只读机台页（可选）
        ├── 易微联场景与开关（可选）
        └── 飞书通知（可选）
```

原则：**打印控制权留给 Handy/Studio；开关控制权可以给易微联 + 我们的场景引擎；档案账本继续是 PrintPilot。**

## 4. 打印机只读：怎么接、能读到什么

只列满足「不影响 Handy/Studio、不做打印控制」的路径。

### 4.1 方案 A — 绑定拓竹云账号（Mars 同款）

- 手机号 / 密码换 Token，连 `cn.mqtt.bambulab.com:8883`。
- 不改打印机模式。Handy / Studio 不受影响。
- Token 会过期（Mars：提前 5 天提醒刷新）。
- 风险：非官方、账号风控可变、TOS 灰区、依赖拓竹云。
- 能读：状态、温度、层数、AMS Lite、任务封面（云历史）、部分耗材类型。
- **只订阅 `report`，不向 `request` 发控制。**

### 4.2 方案 B — 局域网 MQTT 只读（HA 所称 Hybrid）

- 打印机 IP + Access Code，`bblp@打印机:8883` TLS，只订 `device/<SN>/report`。
- **不必开 LAN Only。**
- A1 机内摄像头是低清 JPEG，要局域网 IP；价值低于自定义摄像头。
- 风险：固件改端口 / 证书；打印机 MQTT 客户端很少（论坛说 2–3 个，Studio/Handy 也占坑）。家里探针应只建 **一条** 只读连接，不要再叠 HA。

### 4.3 方案 C — 不接打印机

- 就是现在的 PrintPilot。零协议风险。
- 库存永远靠人盘。易微联仍可单独做开关，只是不能「打印中禁止拉闸」。

**建议：档案层用 C；若要做飞书通知或易微联安全联锁，再加 A 或 B，且只读。** A 和 B 可并存，但客户端名额要省着点。

### 4.4 A1 只读能力对照（来自 HA bambulab 实体表，已去掉控制项）

| 类别 | A1 能读 | 备注 |
|---|---|---|
| 温度 | 热床实际 / 目标，喷嘴实际 / 目标 | 无腔体温度 |
| 风扇 | 冷却扇等 | 无腔体风扇 |
| 进度 | 层数、总层、进度、剩余时间、阶段、状态 | |
| 打印元数据 | 重量 / 长度 / 热床类型 / 封面 | 部分要云账号或从机内读文件 |
| AMS Lite | 4 槽颜色、类型、K 值、估算余量、空/未知 | 无湿度、无烘干 |
| 外挂料盘 | 颜色、类型、K 值 | |
| 诊断 | 在线、IP、WiFi、HMS 错误、固件提示 | |
| 摄像头 | 需本机 IP 的低清 JPEG | 不建议当主画面 |
| 灯光 | 无可用舱灯 | 用易微联灯代替 |

## 7. 易微联（本次叠加的重点）

你已经有多台易微联设备，包括 **三联继电器开关**。这是打印车间里最值得接的「可控制外设」。它不经过拓竹协议，**不会影响 Handy / Studio**。

### 7.1 和「不控制打印机」的关系

| 动作 | 算不算第三方打印控制 | 做不做 |
|---|---|---|
| 用 MQTT 让 A1 暂停 / 加热 | 是 | 不做 |
| 用易微联通道切断打印机 **市电** | 否（控的是继电器） | **可以做**，但必须加联锁 |
| 用易微联开关灯、烘干箱、排气扇 | 否 | **应该做** |
| 打印结束后延时关排气 | 否（读状态 + 控继电器） | 高价值 |
| 打印中禁止切断打印机电源 | 否（保护逻辑） | **强烈建议** |

联锁必须读 A1 状态。没有只读 MQTT，就不要做「远程断打印机电」。

### 7.2 官方 App 还会不会能用

和拓竹相反：**接第三方一般不会把易微联 App 踢掉。**

| 接法 | 官方 App | 配网 / 改 WiFi / 升级 | 同时控制 |
|---|---|---|---|
| 酷宅开放平台 OAuth + 云 API | 继续可用 | 仍用 App | 可以，状态会同步 |
| 局域网协议（设备设置里打开「局域网控制」） | 继续可用 | 仍用 App | 同网优先走局域网 |
| 官方 Webhook / 场景（多为高级会员） | 继续可用 | 仍用 App | 我们只触发 URL，不取代 App |
| 刷 Tasmota / ESPHome | **基本失去官方 App** | 自己管 | 除非你主动放弃 App |

**默认：不刷机。** 继续用易微联 App 配网、改名、升级；我们只做「开关 + 场景」。

### 7.3 三联继电器在协议里长什么样

酷宅设备按 UIID 分型号。三通道典型是：

```json
{
  "switches": [
    { "switch": "on",  "outlet": 0 },
    { "switch": "off", "outlet": 1 },
    { "switch": "on",  "outlet": 2 }
  ]
}
```

- `outlet` 0/1/2 = 通道 1/2/3。
- 可只改其中一个通道，不必三路一起发。
- App 里常见能力：**点动（inching）**、**通电状态**、**互锁（同一时刻只许一路开）**、定时 / 循环定时、场景。
- 互锁适合「加热 / 排气不能同时」这类硬件约束；打印供电 + 照明一般 **不要** 开互锁。

建议在系统里把通道建成「有名字的执行器」，不要停留在「开关 1/2/3」：

```text
设备：车间西墙三联（deviceid 10 位）
├── ch1  打印机市电
├── ch2  顶部照明
└── ch3  排气扇
```

### 7.4 易微联还能提供什么（按你「可能已经有 / 以后会买」列）

| 品类 | 典型能力 | 打印场景 |
|---|---|---|
| 三联 / 四联墙开、继电器 | 分路开关 | 灯、排气、烘干、打印机市电 |
| 普通插座 | 单路通断 | 烘干箱、热床独立供电 |
| 计量插座（POW 类） | 功率 / 电流 / 电压 / 电量 | 打印功耗、电费估算；**2026 年起云端功率刷新被官方限制，优先走局域网** |
| 温湿度（TH） | 读数 + 可选恒温 | 耗材柜、烘干箱；部分型号传感器局域网才稳 |
| 门磁 / 人体 / RF 网桥 | 开关量 | 开门告警、有人亮灯 |
| 场景 / 定时 | App 内自动化 | 可继续留在 App，我们只调用关键场景 |
| Webhook（多在高级会员） | HTTP 触发场景 | 实现快，但依赖会员和额度 |
| iHost / CUBE | 本地中枢 | 你现有硬件是 D2 + 云机，不必先买 iHost |

### 7.5 四种技术接法（易微联专用）

#### E1 — 酷宅开放平台（官方、推荐作「云控」）

- 文档：<https://coolkit-technologies.github.io/eWeLink-API/>
- 开发者中心：<https://dev.ewelink.cc/>
- 用 APPID / APP SECRET，OAuth 绑定你的易微联账号。
- 能拉设备列表、读状态、下发 `switches`。
- 优点：官方、和 App 共存、云机上就能控家里的开关（设备自己连易微联云）。
- 缺点：要申请应用；接口版本会变；依赖外网。
- **适合：腾讯云上的场景引擎。** 云机本来就能出站，不必把 8883 映射进来。

#### E2 — 局域网协议（不刷机，推荐作「快和稳」）

- 设备在 App 里打开「局域网控制」。
- 社区实现最完整的是 [AlexxIT/SonoffLAN](https://github.com/AlexxIT/SonoffLAN)：用易微联账号把 `deviceid` + `devicekey` 拉下来，之后可用组播 / 局域网加密控制。
- `auto` 模式：能局域网就走局域网，否则走云。官方也建议不要纯 local，纯本地不稳定。
- 三联、多通道都支持。
- **不要在云机上跑整套 HA。** 只把「登录拿 key + 局域网开关」抽成 D2 上的小服务。
- 2026 年起：功率 / 电流 / 电压 **云刷新被官方关掉**（给云造成压力）。有计量的插座必须走局域网，否则读数会停。

#### E3 — 官方 Webhook / 场景（实现最快、能力最窄）

- 在易微联 Web / App 里做场景：「若 Webhook → 开通道 3」。
- 我们的系统只要 `GET/POST` 一个 URL。
- 多半要 **Advanced / Prime**。
- 适合：先验证 3 条场景（打印开始开灯、结束关排气、禁止误拉闸用 App 自己做）。
- 不适合：做完整设备台账、按通道精细联锁。

#### E4 — 刷 Tasmota / ESPHome

- 本地 MQTT，最干净。
- 代价：易微联 App 基本告别，以后配网和家人共用都变麻烦。
- **仅当你明确说「可以放弃易微联 App」再考虑。**

**建议默认：E1（云控，做在腾讯云）+ 需要功率读数或断网可用时再加 E2（D2 探针）。E3 可当最小可行验证。E4 默认否。**

### 7.6 打印车间里三联继电器的推荐用法

下面是「A1 只读 + 易微联可写」叠出来的真正价值，Mars 的灯控在 A1 上做不到，用这个补。

| 场景 | 触发（只读 A1） | 动作（易微联） | 注意 |
|---|---|---|---|
| 开始打印 | 状态变为打印中 | 开照明、开排气 | 不要动打印机市电 |
| 打印结束 | 状态变为完成 | 照明可关；排气延时 5–15 分钟再关 | 延时必须我们做或 App 定时 |
| 打印失败 / HMS | 错误标志 | 飞书通知；可选闪灯 | 不要自动断电 |
| 远程断电 | 用户按「断电」 | **仅当状态不是打印中** 才切断打印机市电 | 打印中按钮禁用并写原因 |
| 烘干箱 | 与打印无关 / 定时 | 独立通道 | 可和耗材柜温湿度以后再绑 |
| 离开车间 | 手动场景 | 关灯、关排气；打印机通道看状态 | 一条「离开」场景就够 |

通道命名写进系统，比「三联-2」重要得多。
