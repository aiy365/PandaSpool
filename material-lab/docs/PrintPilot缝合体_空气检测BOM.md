## 5. 接线一览（下单时按这个预留芯数）

```
仓外 ESP32-S3
  5V / GND          →  SEN55 VDD/GND、SPS30 VDD/GND（经排线进仓）
  I2C 3.3V ──电平── →  SEN55 SDA/SCL
                    →  排线 → 仓内 SGP41 + SHT40
  UART 或第二路 I2C ──电平── → 排线 → 仓内 SPS30
  UART2             →  LD2410C RX/TX（3.3V，一般可直连）
```

排线最少 **4 芯**（公共 I2C + 5V + GND，SPS30 也走 I2C）。  
SPS30 走 UART 时改 **6 芯**。

## 7. 验收（货到先看这三行丝印）

1. SEN55 本体印 `SEN55-SDN-T` 或 Sensirion logo，不是「七合一空气模块」杂牌。  
2. SPS30 是金属外壳风扇模组，不是塑料 PMS 长条。  
3. SGP41 能读到 `sraw_voc` 原始值（固件里验），不是只能出 0–500 指数的黑盒。
